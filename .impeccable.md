## Design Context

### Users
Potential employers, collaborators, and tech recruiters visiting a developer portfolio. Browsing context: desktop at work or mobile during research.

### Brand Personality
Sharp, technical, precise — an engineer who ships clean code and cares about craft.

### Aesthetic Direction
Cyberpunk dark theme, but executed with editorial restraint — think architecture magazine, not gaming UI. Neon accents used sparingly, not as the entire vocabulary. Distinctive without being noisy.

### Design Principles
1. **Precision over decoration** — Every element earns its place. No gratuitous effects.
2. **Editorial restraint** — Large type, generous space, disciplined color. Less glow, more structure.
3. **Technical authenticity** — The aesthetic should feel like it was designed by an engineer with taste, not generated by AI.
4. **Contrast through hierarchy** — Use size, weight, and space to create emphasis. Not color gradients.
